## Architecture: SHARP as Universal Orchestration Layer
```
Multiple AI Interfaces (Claude App, ChatGPT App, Claude Code, Custom API)
        ↓
SHARP Orchestration Layer
  • IntentRouter — which AI/interface for each task
  • InterfaceAdapters — normalize requests from all interfaces
  • ContextAggregator — merge context from all sources
  • ToolRegistry — shared tools across all interfaces
  • ValidationLayer — output_validator + retry on every output
  • AuditLogger — complete JSON trace of every decision
  • PerformanceTracker — per-model/interface metrics
        ↓
AI Models Backend (Claude, GPT-4, OpenRouter, Custom)
        ↓
Performance Dashboard — real-time metrics, model comparison, audit trail
```
